## Pravidlá

1. Tu sa robí len vizuál: kompozície, panely, portréty, motion, UI kostra bez finálneho copy.
2. Text sa berie až neskôr z originálu Hii — **neprepisovať** obsah odhadom.
3. Grafika v `assets/graphics-baseline/` je záväzná; obnova: `npm run restore:graphics`.
4. Tehla po tehle: každá zmena = jedna vizuálna tehla (jeden panel / jedna sekcia / jeden efekt).

## Spustenie

```bash
npm install
npm run restore:graphics
npm run dev
```
